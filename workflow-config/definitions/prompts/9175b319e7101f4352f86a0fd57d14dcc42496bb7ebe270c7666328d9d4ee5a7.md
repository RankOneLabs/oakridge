Render the approved plan into `experiments/<area>/studies/<study>/study-plan.md` using the area and study names from the specification. Raise a blocker if either is missing. Include the question, hypotheses, case table by group with controls marked, outcome rules, ordered decision rule, model caps and expected costs with their basis, slice cases and criteria, paid slice settings, full-study repeats, and iteration triggers. Commit the plan with the build.

1. Generate fixtures for the approved slice case IDs.
2. Qualify each fixture using the host instructions. Verify that the reference passes, each omission fails only its own tests, and controls replay in fresh sandboxes. Record `{case_id, reference_passes, omissions_isolated, controls_replayed, detail}`.
3. Hash the generator source, shared visible tests, and hidden-test templates. Record the exact ordered files and hash command in `digest_recipe` as `{files, digest_command}`.
4. Commit the fixtures, generator and qualification work. Publish `slice_build` with the checked commit's head, digest, digest recipe, case IDs, and qualifications.
5. Push and open or update the draft PR against the build base using the pr-operations skill. Publish `pr`.

## Qualification host

- Qualification runs on mcclure, never otto, with at most two scenarios at once.
- Per run:
  1. Image: `docker save <evaluator image> | ssh mcclure docker load`. Then `ssh mcclure docker image inspect <evaluator image> | jq -r '.[0].Id'` must equal the pinned image digest; stop otherwise.
  2. Code: over `ssh -A mcclure`, clone or `git pull --ff-only` the study branch into ~/apps/{{repository_name}}. Run `uv sync --locked --group dev` in the checkout’s experiments directory. Regenerate, and check the tree digest equals the builder's.
  3. Logs: under ~/study-runs/<study>/ on mcclure, never under /tmp. A wake power-cycles mcclure and wipes /tmp.
  4. Results: commit on mcclure and push back over git with the forwarded agent (`ssh -A`). Never copy fixtures or results with scp.
- A connection timeout means mcclure suspended on idle. Wake it with `POST willie:8900/machines/mcclure/wake` and poll `GET willie:8900/machines` until it leaves waking.
- mcclure shuts down only after 30 minutes with no work, so a long qualification run is safe once started.

## Long steps

- Publish a provisional artifact as soon as the work supports it, and publish again with the final numbers.
- Run long commands in the foreground with a polling wait (for example a loop that checks a log or status every 30–60 seconds until done). Never leave a command running in the background across turns.
- Before starting any long step, check that this attempt is still running. If it is not, stop.
- Never end your turn before every artifact this step must publish has been published. Ending early fails the attempt.

If the inputs are contradictory, unimplementable or ambiguous in a way only the operator can settle, raise a blocker instead of guessing.
