# Observation reuse audit

This audit precedes observation lineage, content hashing, grader, and experiment implementation. The sibling repositories were inspected at the exact commits below. Paths in sibling rows are relative to `/home/steve/codes/rol/<repository>/`; Oakridge paths are relative to this repository. The Jev contract was audited inside the JIG repository at `f2430a4`; no separate `jig-jev` checkout exists. `observation/` copies no runtime module from a sibling or from `oakridge-dbos`.

| Source and commit | Audited path | Classification | Reason and observation decision |
| --- | --- | --- | --- |
| Scout `4d90856` | `src/scout/storage/grades.py`; `src/scout/replay/experiments.py` | adapted | Scout retains immutable grade revisions and links an experiment attempt to a versioned parent. Those are useful lineage and retry precedents. Their SQLite rows and Scout-specific evaluation/grade assumptions cannot define Oakridge's `(run_id, artifact_revision_id, item id or JSON path)` address or the new service's storage contract. |
| JIG `5fa9c01` | `src/jig/core/types.py` (`Score`, `ScoreSource`, `EffectiveScore`); `src/jig/eval/dataset.py` | adapted | The score source and append-only history distinguish human from machine judgment, and the JSONL loader validates known fields. The observation contract preserves provenance and typed variants, while leaving JIG's score priority and dataset format in JIG. |
| Jev / JIG `f2430a4` | `docs/jev-contract.md`; `src/jig/core/grading.py` | adapted | Jev distinguishes provider request IDs from local logical calls and returns success/failure as typed variants. Observation execution and grade envelopes retain that distinction. Provider-specific retry classes, probability tolerances and score legends stay at the Jev adapter, rather than becoming generic observation semantics. |
| Assay `4428827` | `src/assay/models.py` (`EvaluationBasis`, `EvaluatorIdentity`, `EvaluationCoordinate`); `src/assay/execution.py` | adapted | Assay separates evaluator identity and basis from an execution coordinate and its result. Observation's question, execution and grade objects keep those roles separate. Assay's arm/cell repeat coordinate and verdict payload are experiment-specific, so no Assay wire shape is copied. |
| Oakridge `eff9e04518d8922e16d01f204ea722b81668768f` | `oakridge-dbos/src/storage/commit.ts` (`canonical()`, `requestDigest`) | **adapted, intentionally distinct** | The recursive key sorting and SHA-256 shape are precedents. That implementation delegates numbers to `JSON.stringify`, has no version tag, and lives behind the package import boundary. Observation pins number formatting and returns `canonical-json/v1:<sha256 hex>` from a local implementation. This entry records the reading required before the new hash was written. |
| Oakridge `eff9e04518d8922e16d01f204ea722b81668768f` | `oakridge-dbos/src/storage/read-store.ts` (`readOperatorEventsAfter`, `readEventStreamBoundary`) | adapted | The `pg_snapshot_xmin` guard keeps a cursor from passing an older open transaction that may commit later. Any later observation change feed should preserve that safety property; this cohort has no feed or database layer to copy it into. |
| Oakridge `eff9e04518d8922e16d01f204ea722b81668768f` | `oakridge-dbos/tests/dependency-graph.ts` | copied | The static module-graph helper is copied and trimmed to the functions the observation boundary test uses, so the test does not import the package it forbids. The copy counts type-only imports as dependencies because they also prevent extraction. |

The producer contract for artifact revisions and item addresses is `workflow-config/development.yaml`, `oakridge-dbos/src/storage/migrations/0001_core.sql`, and `docs/spec-02-handoff.md` at the Oakridge commit above. The `observation/src/wire/envelope.ts` types use those sources for revision fields and stable-id/JSON-pointer/text-span item addressing. Evaluation variants take their vocabulary from the audited JIG, Jev, and Assay contracts; a later capture API must validate any producer-specific body before it can claim one of those variants.
